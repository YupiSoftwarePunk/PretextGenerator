  ### 2. Что не закончено, отсутствует или требует доработки

  1. Архитектурное несоответствие со спецификацией (CLAUDE.md:28-58):
      • В спецификации заявлены изолированные модули:
          • src/lib/storage.ts (работа с хранилищем документов) — отсутствует, вызовы localStorage размазаны по компонентам.
          • src/lib/export.ts (модуль экспорта) — отсутствует, код экспорта жестко зашит в editor/page.tsx и canvasUtils.ts.
          • src/app/preview/page.tsx (отдельная страница предпросмотра и печати/презентации) — отсутствует.
          • src/components/editor/PretextEditor.tsx с подсветкой синтаксиса — вместо него стандартный <textarea> в
          TextEditorPane.tsx:28.

  2. Заброшенная / фиктивная зависимость pretext:
      • В package.json установлена зависимость "pretext": "^0.3.0", которая на самом деле является сторонним устаревшим
      markdown-препроцессором и нигде в коде не импортируется. Движок полностью самописный в PretextEngine.ts.
  3. Синхронизация между Canvas Flow и DOM-стикерами:
      • В Canvas Flow препятствия свободно позиционируются по (x, y) в пикселях.
      • В режиме «README + Стикеры» препятствия работают через CSS float: left/right. Нет бесшовной конвертации позиций при
      переключении вкладок.
  4. Недоработки в редакторе карточек и слайдов:
      • Многослайдовые презентации: при экспорте в PDF/PNG экспортируется только текущий выбранный слайд, нет режима «Экспорт
      всей колоды слайдов».
      • Двухсторонние карточки (Flashcards): нет автоматического формирования двухстороннего листа для печати (Front/Back side-
      by-side).
  5. Шрифты и интернационализация:
      • В layout.tsx:5-23 подключены шрифты Orbitron, VT323, Press_Start_2P с параметром subsets: ["latin"]. Для кириллицы они
      дают сбой (fallback на системный шрифт) либо артефакты.
      • В теге <html> указан lang="en", хотя весь интерфейс на русском языке.
  6. Работа с сохраненными документами в Галерее:
      • Нет возможности переименовать документ прямо в галерее, дублировать или экспортировать документ без открытия редактора.
      • Нет импорта/экспорта всей библиотеки в JSON (бэкап / восстановление).
