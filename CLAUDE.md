# Pretext Slide & Card Generator

## Описание проекта

Веб-приложение для создания визуальных карточек, шпаргалок и презентационных слайдов на базе разметки Pretext. Проект предназначен для развертывания на GitHub Pages.

## Технологический стек

- **Next.js 16** (App Router) - фреймворк для React
- **TypeScript** - строгая типизация (no `any` allowed)
- **Tailwind CSS 4** - стилизация
- **Pretext** - разметка для контента
- **Framer Motion** - анимации
- **Lucide React** - иконки

## Цветовая палитра

### Основные цвета (неоновые, но читаемые)
- **Фон:** Темный фиолетовый `#1a0b2e` - `#2d1b4e`
- **Акцент 1:** Розовый неон `#ff006e` - `#ff3d8f`
- **Акцент 2:** Голубой неон `#00d9ff` - `#42e5ff`
- **Текст:** Светлый `#f0f0f0` - `#ffffff`
- **Вторичный текст:** `#b8b8d1`

## Функциональность

### 1. Типы документов
- **Слайды** - презентационные слайды
- **Карточки** - информационные карточки/флэшкарды
- **Шпаргалки** - структурированные справочники

### 2. Редактор
- Синтаксис Pretext с подсветкой
- Live preview в реальном времени
- Шаблоны для быстрого старта
- Автосохранение в localStorage

### 3. Экспорт
- HTML (автономный файл)
- PNG изображения
- PDF документы
- JSON (для повторного использования)

## GitHub Pages конфигурация

Проект настроен для статического экспорта:
- `output: 'export'` в next.config.ts
- `basePath` и `assetPrefix` для правильных путей
- Оптимизированные изображения отключены

## Стандарты кодирования

### TypeScript
- **NO `any` типов** - использовать строгую типизацию
- Предпочитать `interface` для публичных API
- Использовать `type` для union/intersection типов
- Всегда типизировать пропсы компонентов

### React компоненты
- Использовать функциональные компоненты
- Использовать `'use client'` только когда необходимо
- Предпочитать Server Components где возможно
- Деструктуризация пропсов в параметрах функции

### Стилизация
- Использовать Tailwind утилиты
- Кастомные цвета через CSS переменные
- Responsive дизайн (mobile-first)
- Темная тема по умолчанию

## Ключевые особенности Pretext

Pretext - это минималистичная разметка для создания HTML контента:
- Простой синтаксис для структурирования контента
- Поддержка вложенности и секций
- Возможность кастомизации через атрибуты
